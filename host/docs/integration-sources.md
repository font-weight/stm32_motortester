# Объединённый кандидат приложения

Это объединение программных компонентов для последующего независимого ревью, а не приёмка Windows-продукта. GUI пока остаётся просмотрщиком: USB, управление сеансом через интерфейс и Auto/Normal/Single в нём не подключены.

## Зафиксированные исходники

- Базовый путь и строгие файлы: `2376d325d573b1aa3da6feaf8fddf05d2e1cb601`.
- Ограниченный wire-декодер: `c89c12df984390b34785eba81665abd6418658e2`.
- Сборка окна: `21a2dd8fc53295e7228828d00e886bd28923494c`; поправка тестового helper уже перенесена в базу объединения.
- Байтовый синтетический мост: родитель объединения `4e8d0a3497ee2a8203d2f3e97d8c1293e92dade4`.
- PNG: `2cf1fb83cf7d0dae98656cd6a63a5eea47c7e5c4`. Перенесены GUI, тест PNG, help, format; README объединён вручную.
- Чистый контроллер Normal/analog: `477057aadc9bc8e757bc8ef817125377e816d212`; все 21 новые файлы перенесены без изменения.
- Исправление ограниченной высоты графика: `3b315ac4e1184c4c7e9216ce5594cff0f9beff33`; перенесены класс графика, scroll-область и дополнительный тест. Отдельная проверка этого исправления ожидается.

При независимом ревью исходного объединения `988f2cc094fa82c622f0b20276114e3159ae73d9` выявлено обрезание описаний в боковой панели при минимальном окне 1000×710 (I988-01, REWORK 9,40/10). В следующей дельте панель помещена в прокручиваемую область без сжатия текста/кнопок; добавлена проверка шрифтов 13/18/22 px, доступности действий и возврата к большому окну. Исходный отчёт сохраняется; новое ревью должно привязываться к новому SHA.

Исходные компонентные отчёты независимых критиков доступны в [PR20](https://github.com/font-weight/stm32_motortester/pull/20). Их оценки не переносятся автоматически на это объединение: нужен отдельный отчёт на точный SHA кандидата.

## Фактическая проверка

После исправления боковой панели: 288 тестов прошли на Linux/offscreen, CPython 3.12.14. Это авторская предварительная проверка, не независимая приёмка. Рецепт Windows и закреплённые зависимости не менялись.

Windows Server 2022 проверял только прежний HOST-001 `2376d325`: 76/77 тестов, перекрытие графика/подписи при включённых курсорах. [Журнал](https://github.com/font-weight/stm32_motortester/actions/runs/38055733142). PyInstaller, frozen EXE, лицензии и ZIP до выполнения не дошли. Нужен новый запуск A после проверки исправления.

Чистая Windows 10, реальное устройство, точность шкал и общая приёмка протокола остаются отдельными открытыми критериями. Байтовый эмулятор устройства HOST-007 в это объединение пока не входит.
