# Формат записи MTCAP v1

Статус: собственный формат первого прототипа HOST-001, владелец B. Реализация: `motortester/recording.py` и `motortester/model.py`. Приёмка формата и приложения требует независимого ревью. Это файл на ПК, не USB-протокол. Общий wire-контракт с прошивкой пока не согласован.

## Контейнер

Расширение `.mtcap`; одно полное окно одного канала. Сжатия, исполняемых объектов и внешних ссылок нет. Все целые числа заголовка/отсчётов хранятся little-endian.

| Смещение | Размер | Значение |
|---|---:|---|
| 0 | 8 байт | Magic: `4D 54 43 41 50 00 01 00` (`MTCAP\0\1\0`) |
| 8 | 4 байта | `M`: длина JSON в байтах, uint32-le |
| 12 | 4 байта | `N`: число отсчётов, uint32-le |
| 16 | M байт | JSON-объект, UTF-8 |
| 16 + M | 2 × N байт | Исходные коды в порядке захвата, uint16-le |
| 16 + M + 2 × N | 32 байта | Бинарный SHA-256 всех предыдущих байтов |

Итоговый размер строго `16 + M + 2*N + 32`. Допустимы `1 ≤ M ≤ 16384`, `1 ≤ N ≤ 65536`: максимум 147504 байта. Это защитные пределы загрузчика на ПК, не допустимые профили памяти STM32. Каждый код — целое 0…4095; старшие четыре бита uint16 равны нулю. Дробные числа, bool, отрицательные и выходящие за диапазон коды отвергаются, а не округляются.

SHA-256 выявляет случайное повреждение. Это не подпись, не доказательство происхождения и не защита от автора, пересчитавшего хеш. `origin` также является заявленными метаданными; файл сам по себе не подтверждает измерение прибором.

## Обязательные метаданные

Сериализатор пишет ключи в отсортированном порядке без лишних пробелов, но загрузчик не требует такого порядка. Неизвестные, повторные и отсутствующие ключи отвергаются. `NaN`/`Infinity` недопустимы. Перечисленные ниже поля обязательны, в том числе поля со значением `null`.

| Поле | Тип / значение | Смысл |
|---|---|---|
| `format_version` | integer `1` | Версия формата записи |
| `channel_count` | integer `1` | Один канал |
| `adc_bits` | integer `12` | Диапазон исходных кодов |
| `sample_encoding` | `"uint16-le"` | Представление полезной нагрузки |
| `sample_count` | integer, равен N заголовка | Размер массива |
| `time_basis` | `"nominal_unverified"` | Fs задана номинально, не измерена |
| `amplitude_unit` | `"adc_code"` | Код АЦП, не вольты/кВ |
| `calibration` | `"uncalibrated"` | Нет калибровки шкал |
| `timestamp_origin` | `"host_receive"` | Происхождение времени приёма |
| `session_id` | строка UUID | Идентификатор сеанса источника |
| `sequence` | integer 0…4294967295 | Номер окна внутри сеанса |
| `nominal_fs_hz` | конечное number 1…1000000 | Номинальная частота выборки, Гц |
| `received_at_utc` | строка 1…64 символа, ISO 8601 с UTC-offset 0 | Время приёма на ПК, не время искры |
| `origin` | `"simulator"` / `"device"` | Заявленный источник; транспорт устройства пока отсутствует |
| `trigger_kind` | `"signal"` / `"external"` / `"auto_timeout"` | Причина запуска окна |
| `trigger_index` | integer 0…N−1 или `null` | Для события — индекс внутри массива; для тайм-аута — только `null` |
| `trigger_edge` | `"rising"` / `"falling"` | Выбранный фронт |
| `trigger_level_code` | integer 0…4095 | Уровень запуска в кодах АЦП |
| `pretrigger_samples` | integer 0…N−1 | Фактическая предыстория; для события равна `trigger_index` |
| `complete` | boolean `true` | Прототип принимает только полные окна |
| `firmware_version` | строка 1…128 символов / `null` | `null`, если прошивки нет |
| `protocol_version` | строка 1…128 символов / `null` | Версия wire; у демонстрации `null` |
| `application_version` | строка 1…128 символов | Версия создавшего запись приложения |
| `sensor` | строка 1…256 символов | Описание датчика или явное отсутствие датчика |
| `quality_flags` | массив ≤16 строк по 1…64 символа | Предупреждения источника; неизвестные строки сохраняются |

Управляющие символы U+0000…U+001F, UTF-16 surrogate-коды и U+FFFE/U+FFFF в строковых значениях запрещены. Флаги `incomplete`/`missing_samples` и `complete=false` отвергаются: прототип не умеет достоверно представлять неполные окна и не достраивает их нулями. Это ограничение v1, а не утверждение, что потерянных окон у устройства не бывает.

## Шкалы и качество

Номер отсчёта начинается с нуля. Для события `t[i] = (i − trigger_index)/nominal_fs_hz`, для тайм-аута `t[i] = i/nominal_fs_hz`. Интервал между первым и последним отсчётами — `(N−1)/Fs`; не путать с длительностью N периодов выборки. В GUI/SVG время показано в мс, в CSV — в с.

Коды 0 или 4095 вызывают предупреждение о возможном ограничении; оно вычисляется заново из исходного массива. Крайний код не доказывает насыщение, отсутствие крайних кодов не доказывает исправность аналогового тракта. Пустые `quality_flags` не означают подтверждённую точность.

Смена масштаба графика не меняет коды и Fs. Шкалы напряжения свечи и вывод о состоянии катушки отсутствуют.

## CSV и иллюстрации

CSV: UTF-8, разделитель запятая, десятичная точка, перевод строки LF. Заголовок:

`sample_index,time_nominal_s,adc_code,origin,session_id,window_sequence`

Каждая строка соответствует одному исходному отсчёту; время выводится с 17 значащими цифрами. CSV не содержит всех метаданных MTCAP и не поддерживается как входной формат. Для архива оставлять `.mtcap`. SVG, создаваемый CLI, — иллюстрация, не запись измерения. Экспорт PNG полного MVP пока не реализован.

## Совместимость и отказ

Загрузчик v1 проверяет magic/версию, размеры, точную длину, хеш, JSON, все фиксированные поля и модель захвата. Обрезанные файлы, лишний хвост, неверный хеш, неизвестная версия или неподдерживаемые поля вызывают понятный отказ. Максимальный объём чтения ограничен до разбора JSON.

Изменение обязательных полей или их смысла требует новой версии и проверки старых файлов; молча принимать изменённый формат нельзя. Доказательства совместимости: round-trip и независимый минимальный контрольный вектор в `tests/`. Любой будущий импорт должен сохранять происхождение и не объявлять синтетику реальным измерением.

Сохранение сначала записывает временный файл в той же папке. Без разрешения перезаписи существующее имя не заменяется; при явной перезаписи применяется атомарная замена. Ошибка записи не должна уничтожать прежний файл. Гарантия восстановления после потери питания и поведение всех сетевых/съёмных файловых систем не проверены.
