# Полная поставка независимых WAIT/Stop свидетельств

Исходный архив сохранён побайтно, а не заменён выбранными успешными журналами. MANIFEST.json содержит порядок, длины и SHA-256 частей и восстановленного архива. Каждую base64 часть декодировать отдельно: у каждой собственное padding. Затем объединить decoded bytes по указанному порядку. Перед записью проверить все SHA-256 и длины. Итог: fresh-review-evidence.tar.xz, 10 562 000 bytes, SHA-256 9e0e4a544a19d4c9c57e44bf5915e9722d6ef6d007d756154ff9c0493bcd61dc. Использовать новый выходной файл; прежние результаты не перезаписывать. Архив можно прочитать через Python tarfile в режиме r:xz без запуска содержащихся проб. Проверка независимым Critic-B после remote read-back учитывается отдельным addendum.

Исходный report публикуется без изменений. Его исторические локальные SHA и условия не переписаны под новую публикацию. Новые wrapper/source pins и их проверка описываются отдельно. Ни этот архив, ни прежние PASS не принимают PR95, Windows, физический USB/ADC или общую аппаратную готовность.
## Размер после распаковки и безопасная проверка

В архиве 10 513 обычных файлов, суммарно **2 955 952 519 байт (около 3 ГБ)** без учёта накладных расходов файловой системы. Сжатый размер 10,56 МБ не равен требованию к свободному месту. Сначала проверить длину и SHA-256 каждой части, декодировать их по очереди в новый сжатый файл и одновременно обновлять общий SHA-256. Продолжать только при точном совпадении утверждённого hash архива. Для проверки состава и внутренних checksum использовать потоковый `tarfile.open(path, mode="r|xz")`, читать каждый обычный member небольшими блоками и обновлять его hash без извлечения и запуска. При извлечении отдельно проверить свободное место, допустимые пути и типы entries; не распаковывать автоматически поверх существующих данных.
