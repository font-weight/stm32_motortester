Независимый [check_integration.py](evidence/integration-988/check_integration.py) сам создаёт исходную целочисленную последовательность, побитовый CRC-32 и COBS. Девять DATA имеют разбиение `249×8 + 56`, отличное от штатного примера. Порции: 1, 2, 31, 97, 255, 543 и 4096 байт.

Для каждого окна отдельно проверены:

1. Все 4096 исходных little-endian байт, UUID сеанса и window ID после wire → Capture → MTCAP.
2. `origin=simulator`, отсутствие выдуманной версии прошивки, точный draft SHA, качество и номинальные 50 кГц.
3. Реальный асинхронный `MainWindow.open_path`: новый объект, прочитанный с диска; все Y-точки равны исходным кодам, X-точки равны `(i−512)/50` мс.
4. Курсоры, масштабирование и PNG не меняют объект/отсчёты, исходный файл, текущий путь и признак открытия с диска.
5. Повторное сохранение через GUI даёт побайтно тот же MTCAP; CSV содержит те же коды и синтетическое происхождение.
6. PNG действительно открывается; видимые и встроенные метаданные сохраняют синтетическое происхождение и некалиброванные шкалы.

## 3. Замечание, требующее исправления

### I988-01 · P2 · Обрезаны пояснения боковой панели при штатном минимальном размере

**Место:** `host/motortester/gui.py:134,158–185`, особенно labels на строках 165 и 182. Панель имеет фиксированную ширину 262 px и обычный QVBoxLayout, но не имеет доступной прокрутки или условия сохранения требуемой высоты содержимого.

**Воспроизведение:** обычный шрифт приложения **13 px**, показать окно, создать демо, включить курсоры и уменьшить окно до объявленного минимума **1000×710**. Никакого изменения шрифта или Windows DPI для возникновения дефекта не требуется.

**Факт:** абзацы «Синтетическая синусоида. Прибор и датчик не используются» и «Только просмотр и файлы. USB, Auto / Normal / Single и аппаратные измерения ещё не реализованы» получают по **34 px** высоты при требуемых соответственно **48 px** и **64 px**. Часть текста визуально обрезана и недоступна прокруткой самой панели. [Снимок штатного 13 px](evidence/integration-988/layout-candidate988-13px.png), [измеренные поля](evidence/integration-988/layout-comparison.json).

**Последствие:** выполняемый интерфейс не обеспечивает читаемость всех своих пояснений о происхождении данных и границах прототипа в разрешённом пользователю размере окна. Это нарушение применимой части MVP-U01/H06. Синтетический badge и часть других предупреждений остаются видимыми; потери/подмены данных и ложного аппаратного результата не найдено, поэтому приоритет P2, а не P1.

**Граница регрессии:** в `2376d325` и в отдельном **plot-only** исправлении `3b315ac4` этим же абзацам выделено 45 px; проблема уже частично существовала. PNG добавляет кнопку и уменьшает доступную высоту до 34 px. Объединённый кандидат сохраняет поведение PNG-ветки. Это **не опровержение исправления графика 3b315**: его подписи действительно больше не накладываются на график. Старые частичные оценки не закрывают визуальный дефект общего кандидата.

Принудительные 18/22 px из layout stress-test дополнительно обрезают подписи кнопок. Это вспомогательная проверка устойчивости, **не имитация и не подтверждение настоящего Windows DPI**; для основного замечания достаточно штатных 13 px.

**Ожидаемое исправление:** обеспечить достижимость всего текста и кнопок боковой панели при 1000×710, например прокруткой с сохраняемыми минимальными размерами содержимого. Добавить проверку фактической высоты/доступности wrapped labels, а не только геометрии графика. Повторить UI/PNG, полный набор и независимый сквозной путь на новом точном SHA. Проверяющий production-код не менял.

Других доказанных блокирующих дефектов в заявленной области не найдено. P0/P1 не выявлены.

## 5. Что этим отчётом не принято

- Windows-сборка, frozen EXE, комплект лицензий/ZIP и чистая Windows 10 **не проверены** этим критиком. Известный старый Windows Server 2022 запуск относится только к `2376d325`, завершился 76/77 и не дошёл до PyInstaller. Он не является результатом `988f2cc0`; повторный Windows-запуск остаётся отдельным открытым действием.
- GUI остаётся просмотрщиком. Он не подключает `SessionController`, serial/USB, Auto/Normal/Single, настоящий Run/Stop или настройки прибора.
- Чистый Normal/analog session-модуль и старый window-приёмник имеют **разные явно закреплённые draft-источники** (`b6ae8025…` и `124b3f32…`). Наличие обоих файлов не доказывает готовую диспетчеризацию, RELEASE-цикл или общий принятый контракт.
- HOST-007, байтовый эмулятор полноценного устройства, **не входит** в кандидат. Независимая генерация fixtures критиком не добавляет его в продукт.
- Native USB, устройство, физическое время/амплитуда, LV-001, зажигание, автомобиль и аппаратная безопасность не проверены.
- Общий wire-контракт, сквозная архитектурная приёмка и релиз требуют собственных доказательств и обоих критиков. Этот отчёт не разрешает принимать их и не присваивает уровень MVP.

## Воспроизведение

Из чистого checkout указанного SHA, с установленными зависимостями `host/requirements-gui.txt`:

```sh
export PYTHONPATH=/tmp/motortester-deps:host
export QT_QPA_PLATFORM=offscreen
export XDG_CACHE_HOME=/tmp/motortester-cache
python -m unittest discover -s host/tests -v
python -O -m unittest discover -s host/tests -v
python /PATH/TO/evidence/integration-988/check_integration.py NEW_E2E_DIRECTORY
python -O /PATH/TO/evidence/integration-988/check_integration.py OTHER_NEW_E2E_DIRECTORY
python /PATH/TO/evidence/integration-988/check_sources.py
python /PATH/TO/evidence/integration-988/check_layout.py
```

У source/layout-скриптов путь `ROOT` закреплён на проверенном checkout `/tmp/motortester-host-app`; при переносе меняется только этот путь, не SHA и не критерии. E2E-папка обязана быть новой. Контрольные суммы сохранённых свидетельств перечислены в [SHA256SUMS](evidence/integration-988/SHA256SUMS).
