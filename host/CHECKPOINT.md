## Текущий результат

CLI исполняет 2048 синтетических отсчётов при номинальных 50 kS/s, сохраняет .mtcap, читает его заново, проверяет полное равенство и экспортирует CSV/SVG. Исходные коды uint16-le не заменяются графиком. 20 окон воспроизводятся `scripts/check_first_path.py`. Метка времени этого fixture фиксирована для повторимости, а не представляет аппаратное наблюдение.

GUI на Qt — тёмный русский просмотрщик: открытие/сохранение, CSV, курсоры, zoom/pan/reset, предупреждения и локальная справка. 75 тестов ядра/GUI прошли; фактический help.md также открыт в Qt. Зависимости проверяются на Linux; снимок Qt offscreen является доказательством исполнения здесь, не Windows 10.

## Барьеры и следующий шаг

1. Выполнить проверки точного опубликованного SHA из чистого checkout и предъявить его Critic-B. Независимое заключение ещё не получено.
2. Опубликовать draft PR. Не считать компонент принятым до PASS ≥9.5 и обязательных доказательств.
3. Общий протокол требует двух независимых PASS; после его фиксации добавить host-приём, stream parser, сборку окна, USB/отключение/режимы. Не превращать внутреннее событие в альтернативный контракт.
4. Подготовленная Windows-упаковка не закрывает запуск пакета на чистой Windows 10. Windows executor у B не найден; A проверяет свой доступ. Пользователь просит работать в существующем чате, без создания новых чатов.
5. MVP-U02/U03/U08/U10, полный wire/совместимость, аппаратные LV/ignition проверки остаются открытыми. Курсоры пока в кодах АЦП, не в вольтах без калибровки. Уровень `software-ready` не присвоен.
