# Лицензии: обязательная проверка перед распространением

HOST-001 содержит только кандидат упаковки. Автоматическая копия license-файлов не является завершённым юридическим аудитом и не даёт разрешения на выпуск.

1. Проверить лицензию самого проекта и полномочия на распространение исходников/бинарников: окончательное решение владельца репозитория пока TBD.
2. Сохранить license/copyright/notice для CPython, PySide6, shiboken6, фактических Qt DLL/плагинов, pyqtgraph, NumPy и включённых в NumPy бинарных библиотек, colorama, bootloader PyInstaller и остальных реально распространяемых компонентов. Общая лицензия NumPy не заменяет bundled third-party notices.
3. Проверить `licenses/inventory.json` и скопированные файлы. Пустой список `copied_notices` требует ручной проверки, а не означает отсутствие обязательств. Скрипт копирует обнаруженные уведомления установленных пакетов и `CPython-LICENSE.txt`; полнота DLL-зависимостей и Qt third-party компонентов проверяется отдельно.
4. Для LGPL-варианта PySide/Qt включить необходимые тексты и уведомления; обеспечить доступ к точным соответствующим исходникам библиотек/изменениям выбранным допустимым лицензией способом. Одна ссылка на главную страницу Qt не заменяет выполнение условий. Зафиксировать версию, источник и контрольные суммы такого комплекта перед релизом.
5. Проверить возможность замены/пересборки LGPL-библиотек и отсутствие запрещающих это условий распространения. onedir с отдельными DLL выбран для облегчения этой задачи; это не автоматическое доказательство соответствия. Не использовать компоненты с иными условиями незаметно.
6. Проверить исключение PyInstaller и уведомления bootloader; код упаковщика не передаёт автоматически свою лицензию приложению, но условия включённых зависимостей сохраняются.
7. Сохранить результат аудита рядом с точными source/ZIP SHA. До этого артефакт имеет статус candidate, а не принятого распространяемого релиза.

Первичные источники:

- [Qt for Python: лицензии](https://doc.qt.io/qtforpython-6/licenses.html)
- [Qt LGPL obligations](https://www.qt.io/development/open-source-lgpl-obligations)
- [PyInstaller license and exception](https://pyinstaller.org/en/stable/license.html)
- [CPython license](https://docs.python.org/3/license.html)
- [NumPy license](https://numpy.org/doc/stable/license.html)

`source.zip` от build-скрипта содержит исходники приложения `host/` из указанного Git commit. Он не содержит автоматически corresponding source всех сторонних библиотек и не закрывает пункт 4.
