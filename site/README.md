## Что включено и чего пока нет

В pages.json явно выбраны 32 страницы A; эта стартовая страница — 33-я.
Небольшие JSON-вложения включены как исходные файлы. Под каждой страницей
есть неизменная копия её Markdown. Навигация, стили и включённые материалы
читаются офлайн. Исключённые исторические материалы и внешние первоисточники
помечены «↗ онлайн»; они требуют сети и не считаются автономными вложениями.
Локальные ссылки на исключённые исходники закреплены на commit a855ef341bb5eb8906a16af67f4d6b328f08f02f.

Графические SVG/PDF-экспорты схем и пояснительный PDF **пока не включены**.
Mermaid-блоки показаны как исходный текст диаграммы с явным предупреждением,
без графического рендера и CDN. Печатные стили не означают готовый PDF.
Справка приложения B сюда не импортируется: её актуальная версия относится
к отдельному исходному снимку приложения. Это не завершение MVP-06.

## Собрать HTML

Нужны Python 3.11+ и Pandoc 3 в PATH. Фактически проверяемая среда этой
итерации: Linux, Python 3.12.14, Pandoc 3.1.11.1. Другие версии и Windows
не считаются проверенными автоматически. Генератор ничего не устанавливает,
не загружает, не исполняет прошивку и не публикует сайт.

Из любого каталога, заменив пути на абсолютные:

```sh
python3 -I -B '/absolute/checkout/site/build.py' \
  --source-root '/absolute/checkout' \
  --out '/absolute/existing parent/new offline guide'
```

Выходная папка должна быть новой, вне исходного дерева; её родитель уже
существует. Существующий результат не перезаписывается. Пути с пробелами
нужно заключать в кавычки; symlink-пути не поддерживаются. Запускать нужно site/build.py именно из указанного исходного дерева: чужая
копия генератора отклоняется до создания результата. Исходники должны
оставаться неизменными во время сборки. Это воспроизводимый генератор
доверенной документации, не sandbox для враждебного Pandoc или файловой системы.

Открыть index.html непосредственно браузером, через file://. Сервер,
учётная запись и доступ к Интернету для включённых материалов не требуются.
Можно перенести всю выходную папку в другое место. Нельзя переносить один
index.html без pages, sources и style.css.

## Проверка результата

receipt.json имеет статус PASS только после проверки включённых локальных
ссылок и фрагментов и повторной сверки входных байтов. В нём указаны хеши
исходников/выходов, версия Python, версия и hash Pandoc, команды рендера и явные ограничения.
SHA256 набора входных байтов напечатан на каждой странице: это идентификатор
фактических включённых данных, а не выдуманный Git commit. Отдельный commit
внешних ссылок не утверждает, что все отредактированные страницы равны ему.

При ошибке после создания выходной папки сохраняются частичные результаты
и FAILED receipt; считать их готовым комплектом нельзя. Ошибка предварительной
проверки не создаёт output. Принудительное завершение процесса или потеря
файловой системы может оставить RUNNING/незавершённые данные без финального
свидетельства. Они тоже не являются PASS.

Проверка генератора не заменяет просмотр страниц, таблиц, команд, мобильной
и печатной раскладки в настоящем браузере. Она не проверяет доступность
внешних сайтов и не присваивает аппаратным данным статус измеренных.
