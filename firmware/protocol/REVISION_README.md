# Явный выбор редакции оболочки протокола

Черновой шаг задачи #191. Это общий код упаковки кадра, а не готовая
реализация потокового прибора. Известная прошивка на плате не изменяется.

`mt_wire_encode` и `mt_wire_decode` сохраняют редакцию 0.1 и прежние
сигнатуры. Все существующие вызывающие модули продолжают использовать их.
Вызов старого декодера с корректным кадром 0.2 возвращает ошибку версии.
Автоматического перехода между редакциями нет.

Для отдельного прототипа введены `mt_wire_encode_revision` и
`mt_wire_decode_revision`. Вызывающая сторона явно передаёт major/minor.
Кодер записывает эту пару в оболочку и рассчитывает CRC уже с ней;
декодер принимает только точно ожидаемую пару после проверки длины и CRC.
COBS, порядок байтов, ограничения 512 байт payload / 540 байт decoded /
544 байта framed и условия неизменности результата при отказе сохранены.

Эти функции допускают представление любой пары байтов версии. Это не
подтверждение поддержки сообщений такой редакции. Они не проверяют тип
команды, направление, семантику payload, nonce/sequence, состояние потока,
завершение записи или аппаратную остановку. Семантически ошибочный payload
с правильной оболочкой должен пройти этот слой и быть отклонён следующим.
Вызывать 0.2 из действующего endpoint до отдельной интеграции нельзя.

Один общий алгоритм CRC/COBS исключает две расходящиеся копии. Новые
параметры не добавляют динамическую память или скрытое состояние.
Свойства новой машинной ARM-сборки, стек, временные затраты и физическая
совместимость пока не проверены; старые доказательства бинарника не
переносятся на изменённый исходный код.

Проверки этого шага: строгая нативная C11-сборка; прежние command/session/
stream тесты; независимое сравнение с исходным кодером 0.1, точные общие
кадры 0.2, повреждённые оболочки, границы размеров, неизменность выходов
при отказе и ASan/UBSan. Команды и фактические результаты будут приложены
к точному проверенному снимку. Приёмка общего потока остаётся
BLOCKED_EVIDENCE до проверок обеих конечных точек и независимых заключений.
