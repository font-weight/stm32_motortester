# BOOT002: передача успешного CLK в TIM2/TIME

Локальный черновик Dot A. Область закреплена в
[issue2](https://github.com/font-weight/stm32_motortester/issues/2#issuecomment-6101974205).
Добавлены только `mt_boot_time.c/.h` и этот документ. CLK, TIME, IRQ, USB,
main, linker, старый A-005 и `host/**` не меняются.

Обязательный ABI сборки: 32-битные enum, как у проверенных CLK/TIME;
для GNU Arm использовать `-fno-short-enums` во всех участвующих translation units.
Header проверяет размеры enum при компиляции. Первый авторский ARM object без
этого флага имел неверные смещения полей чужих структур; он сохранён как
отвергнутое свидетельство и не является пригодным компонентом. Сам успешный
compile без проверки ABI недостаточен.

## Зачем нужен узел

Успешный арифметический план ещё не означает настроенный clock. Сам TIME не
проверяет физическую частоту и не доказывает, что перед ним действительно
выполнили reset pulse TIM2. Поэтому helper принимает неизменённый контекст
успешного `mt_clock_apply`, сверяет свежие RCC/Flash с его сохранёнными полями,
наблюдает gate и последовательность TIM2RST 0→1→0, затем вызывает настоящий TIME.
Номинал 72 МГц следует из уже применённого CLK-плана, а не задаётся независимо.

## Обязательные предусловия

- Привилегированный foreground после настоящего system reset. IRQ ещё запрещены
  вызывающим кодом. Helper не меняет PRIMASK и не разрешает прерывания.
- Объекты boot и TIME обнулены один раз. Контекст успешного CLK не меняется и не
  подделывается. Проверенные HSE/режим уже были переданы CLK; defaults нет.
- Единственный владелец RCC/TIM2; нет живых потребителей TIM2, старых timestamps,
  SysTick/IRQ writers и reentry. MMIO callbacks возвращаются своевременно.
- Объекты и контекст callbacks не перекрываются, остаются живы. Используются
  ровно read32/write32/context из CLK, а не другая модель MMIO.

Программная проверка состояния не доказывает физическую историю reset, точность
HSE или достоверность переданных структур. Эти условия остаются обязанностью
интегратора. Helper нельзя вызывать из IRQ или после начала runtime.

## Порядок и допуск

1. Ошибочные pointers/callbacks и уже использованный TIME отклоняются без MMIO
   записей и без разрушения TIME. Повторный/вложенный вызов boot возвращает BUSY.
2. После этих проверок фиксируется необратимая попытка. Любой её неуспех запрещает
   повтор до system reset. Проверяются applied/attempted/cause/recovery CLK и
   свежие CR/CFGR/Flash. Маски привязаны к текущим CLK/TIME для STM32F103.
3. Ожидаются TIM2EN=0 и TIM2RST=0. RMW включает только TIM2EN с readback.
   До подтверждения gate доступ к регистрам TIM2 не выполняется.
4. RMW устанавливает TIM2RST, подтверждает 1, снимает его, подтверждает 0 и
   сохранение gate. Остальные исходные биты APB1ENR/APB1RSTR сохраняются.
5. Повторно сверяется тот же CLK. Настоящий `mt_timebase_init` получает
   72000000 Гц и прежние callbacks. Он сам задаёт PSC/ARR/UG/CNT/CEN.
6. Допуск `ready=1` выдаётся только при успешном здоровом TIME и последней
   сверке CLK. Это разовый результат boot, не постоянно действующий монитор.
   После передачи runtime продолжает штатные проверки TIME на каждом шаге.

Readback одиночный, без polling loop или вымышленной задержки. Проверка порядка
записей не является измерением длительности физического reset pulse.

## Отказы и границы

`cause` сохраняет причину завершившейся попытки. При ошибке ready остаётся 0.
Gate либо сам таймер могут остаться включёнными, а TIME может сохранить владение
после частично выполненного init. Нельзя освобождать/обнулять эти объекты,
подключать потребителей или начинать повторную попытку. Этот ранний boot-путь
требует настоящего reset; helper не выполняет неявный cleanup или Stop живых
потребителей. Отказ финальной проверки CLK не превращает здоровое ранее TIME
в действительный допуск.

Чтения не атомарны. Скрытые transient, конкурирующие writers и остановка CPU при
потере HSE не исключаются этим кодом. Не доказаны аппаратные timings, фактический
reset, полная прошивка, стек, USB enumeration или электрическая безопасность.
Результат остаётся draft до применимого независимого вердикта и обязательных
доказательств. Конкретные выполненные проверки и их границы фиксируются отдельно.

Основания: неизменённые контракты CLK001/TIME001, RM0008 Rev21, RCC APB1 reset и
enable registers; отдельного требования задержки TIM2RST в микросекундах здесь
не вводится. NRST/system-reset timing нельзя переносить на этот бит.
