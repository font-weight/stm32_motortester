# Чертежи низковольтных кандидатов A и B

Здесь находятся новые SVG/PDF-экспорты неизменённых исходников
[analog-source](../analog-source/README_RU.md). Это черновики двух
альтернативных лабораторных модулей и схемы их границ. Полная проверенная
схема прибора с реальной платой, USB, SWD и питанием ещё не готова.
Эти материалы не разрешают монтаж, прошивку или подключение к зажиганию.

## Файлы для просмотра

- Кандидат A, постоянный низковольтный сигнал: [SVG](exports/option-a-dc.svg), [PDF](exports/option-a-dc.pdf).
- Кандидат B, малый переменный лабораторный сигнал: [SVG](exports/option-b-ac.svg), [PDF](exports/option-b-ac.pdf).
- Структурная схема границ модулей: [SVG](exports/structural.svg), [PDF](exports/structural.pdf).
- Функциональные пути: [SVG](exports/functional.svg), [PDF](exports/functional.pdf).

Обозначения и английские примечания принципиальных схем сохранены из
исходника без перевода и изменения электрического содержания. Пояснения,
ограничения и проект измерений на русском находятся в
[исходном описании](../analog-source/README_RU.md) и
[плане измерений](../analog-source/MEASUREMENTS_RU.md).
Названия цепей вроде V3V3_VERIFIED обозначают требуемое условие, а не
уже измеренное напряжение. Номиналы и расчёты не являются измерениями.

## Проверки и происхождение

Экспорт выполнен 12.10.2026 из commit
`dc4df8b735b02f57a2d14f760fff21379ad98ad1`, tree
`5a0ba927d1dbd08422f1927ec4b97c7c2d075240`. При добавлении этого комплекта
в основу `38ece8b490194ff55ffe5ca7848db42acb332859` все 19 исходных
аналоговых файлов остались прежними.

Неизменённый tools/verify.sh завершился с COMPLETE_EXPORT_CHECKS_PASS:
расчёты, повторная генерация без расхождений исходников/BOM, ERC без
нарушений, проверка ожидаемых соединений и 13 непустых выходных файлов.
Использованы Python 3.12.14, KiCad 9.0.2 и Inkscape 1.4.
Сводка действительного наблюдения с хешами исходных экспортов:
[EXPORT_OBSERVATION.json](evidence/EXPORT_OBSERVATION.json).
Это сводка, а не полный необработанный журнал процесса.
Все передаваемые файлы перечислены в [MANIFEST.json](MANIFEST.json);
manifest не включает себя и не заменяет доверенную привязку к Git commit.

Файлы расчётов, netlist и отчёты ERC находятся в evidence.
Визуально проверены все четыре рисунка в SVG и PDF. Проверка экспорта и
читаемости не подтверждает защиту входа, установление АЦП, полосу,
развязку, соответствие компонентов или распиновку конкретной платы.
Физические HW-001A/LV-001, аппаратная и общая приёмка остаются открытыми.

## Особенность PDF

KiCad оставил JavaScript JSInit даже с флагами исключения всплывающих
окон и иерархии. Поэтому два PDF в exports являются отдельно учтёнными
производными: перед копированием структуры документа удалена только
известная ветвь JavaScript. Внутренние переходы к символам сохранены.
На всём графе объектов проверено отсутствие JavaScript, внешних действий,
форм и вложений; разрешены только переходы GoTo к страницам этого PDF.
PNG каждой исходной и производной страницы при 150 dpi совпали побайтно.
Это проверка именно этих файлов, не универсальное обезвреживание PDF.

[PDF_DERIVATION.json](evidence/PDF_DERIVATION.json) связывает исходные и
производные хеши. Два исходных PDF с JSInit сохранены только для проверки
происхождения в evidence/original-kicad-pdf. Для обычного просмотра
используйте ссылки из раздела «Файлы для просмотра», а не эти оригиналы.
Структурный и функциональный PDF не изменялись; JavaScript в них не найден.

## Повторение

Для нового экспорта используйте исходную команду:

```sh
bash "REPO/hardware/analog-source/tools/verify.sh" --out "FRESH_OUTPUT"
```

Каталог результата должен быть новым, его родитель должен существовать.
PDF могут отличаться метаданными времени и хешами при новом запуске;
новые файлы требуют своей проверки. Это не обещание побайтно одинаковых
будущих экспортов.

Для повторения преобразования именно двух сохранённых исходных PDF нужны
pypdf 6.10.0 и pdftoppm из Poppler. Выполните:

```sh
python3 "REPO/hardware/analog-exports/tools/derive_pdf.py" \
  --raw "REPO/hardware/analog-exports/evidence/original-kicad-pdf" \
  --out "NEW_DERIVATION_OUTPUT"
```

Helper закрепляет хеши этих двух PDF и известного JSInit, отклоняет другие
входы и существующий output, сохраняет FAILED/RUNNING при незавершённом
преобразовании. Ранний вариант helper отклонил допустимые внутренние
переходы GoTo; это не дефект рисунков. Исправленный вариант проверяет их
тип и принадлежность страницы документу. Независимый вердикт нового
комплекта фиксируется в его PR; оценка исходников автоматически не переносится.
