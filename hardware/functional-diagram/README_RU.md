# Проектная функциональная схема Э2

12.10.2026. Одноканальный мотортестер STM32F103C8T6: ёмкостный съём,
аналоговые функции, ADC/TIM3/DMA/ОЗУ, управление записью, TIM2, native USB,
приложение Windows 10 и питание. Внешний запуск и управление стендом исключены
по [issue134](https://github.com/font-weight/stm32_motortester/issues/134).
Цель однократной записи — полный разряд с горением и затуханием; параметры
и физическая полнота ещё требуют проверки. Независимый масштаб времени и
амплитуды — [issue136](https://github.com/font-weight/stm32_motortester/issues/136).

Это проект для согласования, не принципиальная схема, монтажная инструкция,
подтверждение электрической безопасности или завершённой интеграции ПО.
Основная версия исходников для сверки функциональных путей:
`192fbb2ef9369bb1c32e11f97263094fca52763f`.
Core-only «Запись сейчас» рассматривается отдельно в draft PR135;
целевые функции не объявлены уже работающими через USB.

## Файлы

- `output/Мотортестер_функциональная_схема_Э2.pdf`: один лист А3 для печати.
- Соответствующий SVG: векторный лист; текст представлен контурами.
- `output/Описание_функциональной_схемы_мотортестера.docx`: редактируемое
  пояснение всех функциональных частей, режимов, границ реализации и источников.
- `build_scheme.py`, `build_description.py`: исходники генераторов. Для изменения
  надписей редактировать текст в этих файлах; не требуется вручную менять контуры.
- `assets/`: OpenGOST type B и неизменённая лицензия OFL 1.1.
- `DELIVERY_SHA256.json`: точные хеши файлов данного выпуска, кроме README и
  самого manifest. Это контроль целостности, не подпись или аппаратная приёмка.

## Воспроизведение

Нужен Python 3 с пакетами из `requirements.txt`. При подготовке использованы
ReportLab 4.4.9, fontTools 4.61.1, python-docx 1.2.0. В каталоге пакета выполнить:

```sh
python3 build_scheme.py
python3 build_description.py
```

Генераторы создают `output/`, а генератор схемы также `qa/text_geometry.json`.
После изменения заново открыть PDF/SVG и отрендерить все страницы DOCX.
Для растровой проверки PDF можно использовать Poppler:

```sh
pdftoppm -scale-to 2100 -png -singlefile output/Мотортестер_функциональная_схема_Э2.pdf qa/scheme
```

Даты и ZIP/PDF-метаданные повторного экспорта могут изменить SHA PDF/DOCX;
сравнивать нужно также содержимое и отображение. Manifest относится к поставленным
байтам и не пересоздаётся автоматически. SVG детерминирован при указанном шрифте
и версиях; после намеренного изменения исходников его хеш тоже изменится.

## Оформление и проверка

Кириллический код Э2. А3: 420×297 мм, рамка 20/5 мм, основная надпись формы 1
185×55 мм. Линии связей 0,35 мм; основные линии рамки 0,7 мм. Шрифт типа Б,
основные надписи h=3,5 мм, компактные h=2,5 мм; в PDF встроен, в SVG — контуры.
Печатать 100 %, без подгонки. Обозначение `МТ.00.00.000 Э2` временное.
Имена, подписи, организация и окончательные позиции будущей Э3 не выдуманы.

Применимость редакций в Казахстане проверена по официальным карточкам:
[2.701-2008](https://new-shop.ksm.kz/catalog/document/38206/),
[2.702-2011](https://new-shop.ksm.kz/catalog/document/46766/),
[2.104-2006](https://new-shop.ksm.kz/catalog/document/15565/),

Поставленные PDF/SVG и четыре страницы DOCX прошли независимую визуальную
проверку и сверку функциональных связей. Этот факт не подтверждает аппаратную
реализацию, Windows-квалификацию или возможность безопасного подключения к зажиганию.
