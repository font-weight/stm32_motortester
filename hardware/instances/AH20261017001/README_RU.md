# AH20261017001: входы первого частного низковольтного кандидата

Это исходные параметры и расчётные основания одного экземпляра владельца.
Это не универсальный пример Blue Pill и не разрешение прошивки. Бинарные
ELF/BIN/HEX в этот исходный PR не включены; REGISTRY.json фиксирует хеши
локально построенного кандидата, а не обещает наличие файлов по этим путям.

Основа firmware: 96002ce62bb5c065ac665ca81059c4a62e90d1dd, wire0.1.
Исходный полный build_image.py выполнен без изменения с резервом6144B и
запасом3080B. Статус CONDITIONAL_STATIC_LINK_CHECKS_PASS означает только
проверку static image. Образ назван CALLER_ASSERTED_NOT_FLASH_APPROVED.
hardware_verified=false и flash_approved=false сохраняются.

Файлы:
- AH20261017001-board.json — строгий data-only вход существующего генератора.
- POWER_BASIS_RU.md — расчёт100mA для USB-only bare board при комнатной температуре.
- DECISIONS_RU.md — программные решения, память/тактирование/идентичность и ограничения.
- REGISTRY.json — точные хеши исходных входов и построенных артефактов.

Идентификаторы фотографий и ссылки на непубличные материалы удалены
из публичной редакции; оригинальные свидетельства сохранены отдельно. Первичные внешние
источники приведены прямо в записках. Полные scoped review/логи сохраняются
отдельно и будут приложены к проверяемому комплекту; отсутствие такого
комплекта нельзя заменять флагами JSON или одним хешем.

Особенно важно: VID/PID1209:0001 разрешён владельцем диапазона только для
private/in-house testing (https://pid.codes/1209/0001/). Он не уникален во
всём мире и не предназначен для устройств, которые распространяются,
продаются или производятся. Это не выделенный проекту постоянный PID и не
USB-IF certification. Не копировать serial AH20261017001 на другую плату.
Публикация исходных параметров не разрешает использование этой identity
за пределами указанного частного теста.

Шесть caller attestations ссылаются на документальные/расчётные основания:
фото маркировки STM32F103C8T6 и документированные64KiB/20KiB; номинальный
кварц8MHz; сообщённая владельцем прозвонка R8 1,5kΩ D+→3.3; расчёт бюджета;
условия private-test VID/PID; назначенная связь serial с экземпляром владельца.
Это не автоматическая аутентификация MCU, измерение частоты/тока или USB-test.

До реальной записи остаются отдельные условия exact image/hookup review
и инструкция оператора. До реального захвата — readback выбранного образа,
наблюдаемые USB/HELLO/CAPS/CONFIG, физические VDDA/ADC_IN и точный пакетB.
DTR=1 пока требует явного согласования B. Нет разрешения открыть порт,
вооружить ADC, подключить высокое напряжение или объявить LV-001 выполненным.
