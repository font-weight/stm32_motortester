# Ручной запуск личного тестового комплекта

Статус: проект инструкции для владельца. Сама инструкция не подтверждает готовность комплекта, принятие условий или разрешение на подключение платы. Применять только после доставки проверенного комплекта с конкретными контрольными суммами.

Все пути ниже указаны относительно корня распакованного внешнего комплекта.

## До запуска

1. Получите в этой переписке обозначение проверенного комплекта, SHA-256 архива и EXE. Сначала сверьте полученный архив с указанной суммой. В Windows можно использовать штатную команду `certutil -hashfile "полный путь к файлу" SHA256`. Для проверки архива и EXE выполняйте её отдельно. Несовпадение означает остановку.
2. Распакуйте внешний комплект обычным средством Windows. Внутренний архив `build/Motortester-windows-x64-candidate.zip` сохраните неизменным; его содержимое целиком извлеките в `evidence/support/launcher/app/`. Должны получиться `evidence/support/launcher/app/Motortester/Motortester.exe` и все соседние файлы. Не переносите отдельно EXE или DLL. SHA-256 EXE должен совпасть с сообщённой суммой и полем `application.sha256` в `evidence/support/launcher/launch-manifest.json`.
3. В уже имеющемся разрешённом просмотрщике прочитайте документы из `evidence/support/launcher/terms/`: COMPONENT-TERMS.txt, MICROSOFT-RUNTIME-NOTICE.txt, MICROSOFT-VISUAL-C++-V14-RUNTIME-LICENSE.docx и его текстовую копию. Полный документ Python находится в `evidence/support/launcher/app/Motortester/licenses/CPython-LICENSE.txt`. Официальный DOCX сохранён; текстовая копия может не передавать автоматическую нумерацию Word. Если документы невозможно прочитать, сообщите об этом до согласия.
4. После чтения ответьте в этой переписке, согласны ли вы с применимыми условиями компонентов именно доставленного комплекта. Запрос будет привязан к его фактическим контрольным суммам. Прежнее разрешение на публикацию документов не считается этим согласием. Согласие относится к вам и указанным условиям; оно не принимается за других получателей.

## После явного согласия

Самостоятельно откройте проверенный `Motortester.exe` обычным способом из его полного каталога. PowerShell-сценарий для этого ручного пути не запускается. Последний абзац COMPONENT-TERMS.txt о вводе фразы и повторном запросе относится к использованию Start-Motortester.ps1. Такой повтор при каждом запуске не является отдельным требованием Microsoft для этого ручного пути.

Ручной путь не выполняет автоматические проверки путей и повторную проверку файлов непосредственно перед запуском, предусмотренные сценарием. Поэтому проверка доставленных файлов остаётся отдельным обязательным шагом; ручной запуск не считается проверкой самого сценария.

Если просмотр или запуск блокируется действующей защитой Windows, остановитесь и пришлите точный текст сообщения. Не меняйте политику PowerShell, не снимайте блокировки загрузки, не используйте обход AppLocker, повышение привилегий или «Выполнить в любом случае» по этой инструкции. Успешная проверка сценария на сервере не подтверждает разрешение его запуска на вашем Windows 10.

Сначала используйте только эмулятор, при отключённой плате. Выберите «Эмулятор (синтетика)», затем «Подключить · без запуска захвата»: до этого запись недоступна. Отдельная репетиция на этом EXE: Auto, pretrigger 0, 1000 мс, отключённое «Событие запуска в эмуляторе», Record → дождаться нового полного окна именно этой записи → «Стоп» → «Сохранить сеанс .mtrec…», дождаться завершения → повторно открыть запись. Если новое полное окно не появилось за 5 секунд, нажмите «Стоп» и остановите проверку. Ошибки и частичные записи сохраняйте для разбора; не выдавайте их за успешный результат и не переходите к плате. Проверяются 2048 отсчётов, причина auto_timeout и отсутствие маркера/индекса запуска. Только после успешной репетиции следуйте отдельному BRINGUP_PLAN_RU.md; его ограничения времени остановки/сохранения/закрытия остаются обязательными. Принятие условий компонентов само по себе не разрешает прошивку, открытие реального COM-порта или измерения.

Лицензии и права на Motortester, Python, Qt/PySide/shiboken, NumPy и другие независимые компоненты сохраняются. Ручной путь предназначен для этого личного теста владельца; его согласие не заменяет условия для последующих получателей и не является заключением о юридической достаточности для любых способов распространения.
