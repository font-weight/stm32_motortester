# Происхождение source-only пакета

12.10.2026, черновая передача по issues29/90. Этот набор предназначен для
получения редактируемых схем и повторного локального экспорта. Он не является
принятой аппаратной конструкцией, разрешением монтажа или подключения.

Схемы, библиотека, проекты, BOM, расчётный/схемный/диаграммный генераторы и
checker перенесены без изменения из восстановленного локального кандидата
ANALOG-001. Его исторический 36-файловый manifest имел SHA256
889318f4c4a0d80b3678b595b724591ef281af3b5dd21ae4fb6f956dbbd413ea.
Часть старых бинарных экспортов ранее была недоступна; новые экспорты не
называются исходными потерянными байтами. Старый pending binary publication
не возобновляется этим source-only изменением.

Полный fail-closed экспорт tools/verify.py и wrapper взяты из отдельно
проверенного tooling r2; verify.py SHA256:
db5a5d375fea02b31d9141437d8865ab5f0ff7f8c3348c4879db27d0c9c9d036.
README изменён для описания этого состава и пути запуска; SOURCES.md
переведён на русский с сохранением ID, ссылок и численных ограничений. Новые SOURCE_MANIFEST.json и этот документ описывают передачу.
При первоначальной передаче MEASUREMENTS_RU был сохранён как исходный проектный материал. Уточнение владельца 12.10.2026 по issue134 обновляет в README_RU и MEASUREMENTS_RU только требования к внешнему запуску; неизвестные параметры, ограничения и реальные проверки сохраняются. Текущий SOURCE_MANIFEST обновлён для этих документов; исторический manifest и оценки прежней передачи не переименованы.

Включены только UTF-8 исходники/документы. PDF, SVG, netlist, ERC, старые логи
и review-отчёты не включены. Команда создаёт 13 обязательных новых результатов
в отдельном каталоге и сохраняет их SHA/команды/ограничения. KiCad PDF могут
содержать встроенный JavaScript; проверка экспорта его не исполняет, PDF не
обезвреживает. Для статического просмотра доступны создаваемые SVG.

SOURCE_MANIFEST.json перечисляет все остальные файлы пакета, но не себя.
Это контроль целостности, не подпись и не защита от замены manifest вместе
с файлами: доверять следует проверенному Git commit/tree. Для приёмки передачи
нужен новый независимый вердикт именно этого состава. Оценка tooling r2 и
исторические оценки восстановления не объявляются оценкой этой публикации.
