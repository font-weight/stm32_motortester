# Диплом: микроконтроллерный мотортестер

Прибор для записи и просмотра сигналов системы зажигания на ноутбуке. **Текущий MVP: STM32F103C8T6, встроенный АЦП, один канал, native USB Full Speed и приложение Windows 10 с тёмной темой.** Автоматический анализ и ML отложены; второй канал — после готовности основы. Сохраняем возможность последующих расширений.

Исходные условия: **до 100 000 KZT, семь месяцев от 23.09.2026**; есть Blue Pill с сообщённой маркировкой STM32F103C8T6, ST-Link V2, мультиметр и китайский ЛБП до 24 В с неизвестным током. Ограниченно доступен осциллограф в вузе. Для измерений планируется отдельный стенд. Nissan Almera 2002 года, предположительно 1,8 л, остаётся дополнительным объектом: тип зажигания пока неизвестен. Подробности — в [требованиях](requirements.md).

## Сейчас

На 10.10.2026 подготовлен локальный firmware draft с воспроизводимой object-сборкой и условными static-link/ELF/BIN/HEX проверками. Проверенные локальные области не означают приёмку MVP: проект остаётся **BLOCKED_EVIDENCE, score:null**. Новый локальный кандидат не опубликован; программная и аппаратная готовность не объявлены. Фактические проверки и ограничения — в [прогрессе](docs/progress.md). Windows-направление ведёт Dot B; его готовность этим firmware-кандидатом не устанавливается.

Распределение: Dot A сам пишет код и ведёт прошивку/электронику, Dot B сам пишет и ведёт Windows-приложение целиком. У каждого независимый критик; результат с оценкой ниже **9,5/10** не принимается. Общие решения и релиз проходят обоих критиков по [правилам приёмки](docs/quality-gate.md). Общую интеграцию выполняет A. Исходный пакет передачи DOC-005 — редакция 1.2, архив с суффиксом `v3`; это историческая постановка, последующие указания владельца имеют приоритет.

Для передачи: основной Dot получает [DOT_START.md](DOT_START.md), второй — [DOT_PEER_START.md](DOT_PEER_START.md); обоим нужен доступ ко всему [репозиторию font-weight/stm32_motortester](https://github.com/font-weight/stm32_motortester). Подробное [ТЗ MVP](docs/mvp-spec.md) и [правила совместной работы](docs/coordination.md) задают требования; их наличие не доказывает выполнение всех пунктов.

Следующие условия интеграции: действующие независимые вердикты конкретной версии, согласованные межкомандные контракты и обоснованные реальные board inputs, резерв стека и запас. Затем нужен сквозной низковольтный опыт по USB по правилам проверки. Конкретные питание/соединения платы ещё нужно проверить; независимая работа над приложением и аппаратным трактом продолжается. Подбор катушки и коммутатора (**HW-001B**) идёт параллельно. G474, внешний АЦП, Ethernet, .dm2 и ML находятся вне MVP; менять платформу без пересмотра задания не нужно.
