# Словарь проекта

| Термин | Что означает здесь |
|---|---|
| АЦП | Преобразует напряжение на входе в число. Его пределы не равны допустимому напряжению на бронепроводе. |
| Fs, MS/s | Частота выборок; 1 MS/s — миллион отсчётов в секунду. Не равна частоте обновления графика. |
| Разрядность / ENOB | Число бит кода / эффективное число бит с учётом шумов и искажений. Большое число бит не гарантирует точность системы. |
| Аналоговая полоса | Частоты, которые тракт передаёт с заданными изменениями амплитуды и фазы. |
| Алиасинг | Высокочастотный сигнал после недостаточно защищённой оцифровки выглядит как другой, более низкочастотный. Фильтр нужен до АЦП. |
| DMA | Аппаратная передача отсчётов в память без выполнения инструкции процессора на каждый отсчёт. |
| Предыстория | Часть записи до события запуска; получается из кольцевого буфера. |
| Триггер / запуск | Условие фиксации окна. Для стенда — отметка команды, а не обязательно обнаруженная искра. |
| Dwell | Время накопления энергии в катушке. Выбирается по конкретным деталям и проверяется, а не назначается универсально. |
| PHY / MAC | Физическая часть интерфейса / канальный контроллер. Наличие MAC или HS-контроллера не означает наличие всех нужных микросхем на плате. |
| USB FS / HS | Full Speed / High Speed. Скорость линии отличается от полезной скорости приложения. |
| Клиппинг | Ограничение амплитуды трактом: вершина обрезается. Такая запись может быть непригодна для части признаков. |
| Сегментация | Разделение длинной записи на события/окна для анализа. |
| Признак | Характеристика окна, например наличие отклика или длительность его участка. Физическую трактовку подтверждают отдельно. |
| Метка | Целевое значение для обучения и проверки, например независимо установленное состояние катушки или исход команды. Основание метки записывают; вывод нашей модели его не заменяет. |
| coil_id / session_id | Физическая катушка / общий сеанс опыта, который может содержать обе сравниваемые катушки. Нужны для проверки независимости данных. |
| mounting_id / condition_id | Отдельная установка датчика / набор условий: питание, управление, вторичная цепь и настройки тракта. |
| Качество / отклик / разряд / состояние | Пригодность записи / обнаруженный электрический сигнал / независимо наблюдавшаяся искра / подтверждённое состояние катушки. Эти уровни не взаимозаменяемы. |
| Busy / интервал нечувствительности | Прибор занят и не готов сохранить новое окно. Такая команда учитывается, но не становится примером «искры нет». |
| Аппаратная отметка запуска | Привязка события к счётчику времени/выборок прибора; время получения USB-пакета на ПК её не заменяет. |
| Утечка данных | Информация из проверки попала в обучение или настройку и завысила оценку качества. |
| Групповая проверка | Целые катушки/сеансы удерживаются вне обучения, вместо случайного перемешивания соседних импульсов. |
| Обнаружение отклонений | Поиск необычного сигнала. Сам по себе не определяет причину и не доказывает неисправность. |
| Базовое решение | Простой алгоритм/правило, с которым сравниваем ML. |
| Domain shift | Отличие условий данных, например датчик DIAMAG против нашего датчика или стенд против двигателя. |
| PCB / BOM | Печатная плата / перечень компонентов с характеристиками и стоимостью. |
| TBD | Значение пока неизвестно; рядом должен быть способ и этап его определения. |
