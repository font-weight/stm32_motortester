# Условная граница стека: сохранённые доказательства

**Это пакет для чтения и проверки точных байтов, не готовая прошивка.**
Единственный исполняемый ARM ELF внутри — историческая модель размещения
с недопустимыми нулевыми board inputs. Его имя содержит
`TEST_ONLY_INVALID_BOARD_STATIC_PLACEMENT_NOT_FLASHABLE`. **NEVER_FLASH:**
не прошивать и не запускать. Остальные 33 ARM-файла — исходные объектные
модули; они не являются аппаратно проверенным образом.

## Состав и версия

В `evidence/` сохранены 112 файлов без изменения исходных байтов:
78 текстовых/JSON/Python материалов (3 533 227 байт), исторический ELF и
33 упорядоченных объекта (334 228 байт). Всего 3 867 455 байт.
`manifest.json` содержит относительные пути, размеры, SHA-256 и исходные
исторические пути. Дополнительно закреплены 85 файлов исходников/ссылочного
манифеста из дерева R8 `15c912a75bdb61546148f0abe483706d977955c1`,
опубликованного как commit `6851f4880143692a28b29867cdc14b0c2a5fa0bb`.

- [Исходный отчёт](evidence/device-stack-bound/REPORT_RU.md), разрешённый
  граф вызовов, машинные кадры, indirect targets, вычисляемые переходы,
  relocation/disassembly и исходные команды объясняют расчёт.
- Независимый обзор и последующие обзоры переноса границы сохранены
  отдельно от авторского доказательства; их область не расширяется
  фактом копирования в репозиторий.
- 32 выбранных C `.su`, исходный map и ELF/33 объекта позволяют сопоставлять
  числа с конкретными байтами. Рукописный reset — отдельный 33-й объект.
- Два patched TinyUSB source и недопустимый zero-board fixture сохранены
  явно. Другие относящиеся к доказательству исходники уже есть в R8;
  их идентичность проверяется через `source_dependencies`.

Исторические manifests сохранены полностью и могут ссылаться на материалы,
которые не входят в выбранный пакет. Они не являются списком поставки:
актуальный список поставки — только новый `manifest.json`. Компилятор,
интерпретатор Python, cache и целые рабочие каталоги не включены.

## Безопасная локальная проверка идентичности

Из корня этого checkout, Python 3.12+ со стандартной библиотекой:

```sh
python3 -I -B tests/device-stack-proof/verify.py
```

Либо задать канонический абсолютный `--root` для копии checkout. Символические
ссылки в проверяемых путях отвергаются; пробелы в пути допустимы. Проверка
читает файлы и пишет только результат в stdout/stderr. Она не импортирует и
не исполняет исторические скрипты, не вызывает compiler/objdump/Git, не
линкует и не взаимодействует с платой. Не требует старых абсолютных путей.
Лишние файлы внутри `evidence/`, отсутствующие/изменённые файлы и несовпадение
закреплённых исходников отклоняются. Пустые дополнительные каталоги не
являются доказательствами и не влияют на результат.

Успех — `EVIDENCE_IDENTITY_PASS`: совпали 112 поставляемых файлов и 85
исходных зависимостей. Это **не повторное выполнение доказательства**;
`proof_reexecuted`, `stack_bound_transferred`, `hardware_verified` и
`flash_approved` остаются false. Проверка не является защитой от
враждебной одновременной подмены файлов. Не обновлять hashes при изменении
firmware без нового применимого независимого анализа.

## Смысл числа 3016 байт

Для точного закреплённого кода: foreground вместе с main — 2640 байт;
одна USB IRQ software-chain — 264; аппаратная exception allowance — 36.
Нормальный верхний предел: 2640 + 264 + 36 = 2940. Допускаются ещё терминальные
HardFault и NMI по 36: 3012, округление до кратного 8 даёт **3016 байт**.
Startup рассмотрен отдельно: 288 байт.

Число условное: privileged reset-only MSP/STKALIGN; только равноприоритетные
USB IRQ19/20; неизменные callback targets; терминальные fault handlers;
целая память/указатели; нет нового deferred producer, RTOS/PSP, рекурсии,
динамического стека или иных прерываний. Нулевой board fixture не использован
для отсечения рабочих путей. Это не измеренный high-water, не выбранный
production reserve и не инженерный запас. Применимый перенос к другому ELF
выполняется отдельным [static-link recipe](../../firmware/build/BUILD_IMAGE_README.md)
после всех его проверок; простого совпадения числа недостаточно.

## Что пока не воспроизводится переносимо

Сохранённые `replay.py`, анализаторы и независимый исторический скрипт
содержат абсолютные пути. **Не запускать их как инструкцию для этого архива:**
они требуют прежнюю 344-входную среду и могут писать рядом с исходными
материалами. Их bytes здесь нужны для анализа алгоритмов и происхождения.
Новый portable replay/regeneration wrapper в эту итерацию не входит.
Подготовка toolchain и повторная генерация baseline ELF остаются отдельной
задачей. При пересчёте равнозначных путей tie-breaking графа может менять
порядок выбранного пути без изменения численной границы.

Пакет не подтверждает физические IRQ/USB/ADC timing, реальную память MCU,
board inputs, Windows interoperability, электрическую безопасность,
LV-опыт или готовность MVP. Формально: **BLOCKED_EVIDENCE, score:null**.
