# Проверка кодера редакций 0.1 / 0.2

Из корня репозитория:

```sh
sh tests/protocol/revision-codec/run.sh
```

Нужны Python 3, C11-компилятор и ASan/UBSan. По умолчанию создаётся отдельный
временный каталог, путь выводится в конце. Для сохранения в выбранный новый
каталог передайте его первым аргументом. Генератор читает текущие JSON из
protocol/, компилятор — текущие firmware/protocol/mt_wire.c/.h. Копии
проверяемого кодера в тестах нет; build/corpus создаются вне исходного дерева.

baseline_mt_wire.c/.h — неизменные снимки legacy-кодера из
7ddbb22692d3bc5ae2c44f2b857d8f09639919b9; эквивалентный опубликованный commit
770c468491b4c469336db7fa9ee3ee7653013481
(tree 8488ceaebdc8ac880c9e7d9073d4846077043014). SHA-256:
- C: 84677c6054294cc1d3dbf7095352a265fc038288693e890f6673d911da5bdb8c
- H: c61ef9e7beba2947724ef2006ce305cdb7dd22204d03c9524b4a57fe2f3ae547

Baseline собирается со своим принудительно включённым заголовком;
переименованы только внешние символы для совместной линковки с кандидатом.
Генератор использует независимые struct/zlib и COBS по ненулевым сериям,
не вызывает кодер прошивки или генератор общих векторов.

Авторский запуск интеграции: GCC 14.2.0, строгий C11 и ASan/UBSan прошли.
Корпус содержит 4182 случая (4128 допустимых оболочек, 54 отказа), плюс
20000 детерминированных повреждённых входов с точным размером выделения.
SHA-256 сгенерированного корпуса:
d71a940fca59ee0a3f1ac9e9cf42a0f806e56fc8ef067304e5b0a6defed00388.
Число случаев описывает покрытие, а не оценку качества или полное доказательство.

Проверяются точные общие кадры, все длины payload 0–512 и четыре шаблона,
границы COBS, отдельные major/minor mismatch, порядок ошибок length/CRC/
version/reserved, NULL/недостаточная ёмкость и неизменность выходов при отказе.
Десять семантически ошибочных payload из векторов 0.2 намеренно принимаются
слоем framing: их должен отклонить будущий обработчик состояния/сообщений.
Старые encode/decode сравниваются с сохранённым baseline побайтно.

ASan запускается с detect_leaks=0: LeakSanitizer в среде под ptrace завершился
ошибкой окружения. Проверка утечек не заявлена. Начальная неудачная попытка
линковки старого session-теста без mt_command.c исправлена в рецепте;
прежние command/session/stream тесты прошли с полным набором protocol-модулей.

Это нативная проверка оболочки. Она не запускает Windows, USB, АЦП,
ARM-прошивку или автомат состояний потока. Непересечение объектов —
предусловие API; недопустимые указатели и произвольное aliasing не проверяются.
Реальная производительность, стек и карта памяти ARM требуют отдельной
проверки. Приёмка протокола/прибора остаётся BLOCKED_EVIDENCE.
