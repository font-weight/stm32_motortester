# Статическое свидетельство отдельного диагностического образа

Архив содержит ELF с символами, исходники/объекты и переносимый verifier.
Он не содержит пользовательский комплект прошивки или разрешение на неё.
Exact image/source/archive/manifest hashes находятся в reference.json.

Распакуйте архив в новую отдельную папку. Внешний toolchain должен содержать
закреплённый arm-none-eabi-objdump; его SHA-256 проверяется verifier.
Повтор выполняется так (подставьте действительные пути):

```
python3 -I -B /путь/board-instrumented-stack-proof/verify_package.py --objdump /путь/arm-none-eabi-objdump
```

Не использовать -O/-OO. Запуск создаёт новый каталог результатов, не переписывая
замороженные исходные данные. Полный отчёт и условия — REVIEW_RU.md внутри архива.
Отдельная независимая перепроверка — BOARD_STATIC_CROSSCHECK_RU.md рядом.

Для точного ELFe32461ba...b807f2 рассчитано 3228 байт, минимум с выравниванием
3232 байта. Объявленный резерв8192 даёт4960 байт арифметической разницы; это не
измерение high-water и не обещание физической безопасности. Все условия
Reset/privileged MSP/STKALIGN/IRQ priorities/terminal fault handlers/callbacks
остаются обязательными. Source/native telemetry verdict опубликован отдельно
в tests/stream-telemetry/reviews; этот архив не заменяет физический опыт.

Board JSON содержит исторические caller attestations. Повторная компиляция
не подтверждает частоту кварца, подлинность MCU, питание, USB права или wiring.
Новый build0x53545231 отделяет кандидат STREAM от прежней оконной прошивки.
Provisional1ms timing input не является доказанным transaction bound.

В parser-correction сохранена воспроизводимая поправка старого PR204:
regex мог принять mnemonic addcc за поле machine bytes и пропустить uxth.
Пересчёт старого ELF не изменил численную границу3164/3168, но исправил покрытие
инструкций9→10. Старый архив не переписан. Новое свидетельство использует
исправленный lexer и отрицательные проверки.

Аппаратные проверки, Windows collector, HOST доставка, qualified timing,
готовность прибора и разрешение прошивки остаются отдельными вопросами.
